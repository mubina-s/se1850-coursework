# Attribution & Academic Context

This repository is a curated archive of coursework completed for SE 1850 at Iowa State University.

Some lab source files were originally distributed with course-provided starter structure, comments, function prototypes, or instructions. Where those comments or attributions were present in the original coursework files, they have been retained rather than removed.

The implementations shown in this repository reflect my submitted coursework and learning at the time of the class. They are not presented as official course solutions or production-ready software.

## Public Portfolio Cleanup

For this GitHub portfolio version, the following material from my original course folder was intentionally excluded:

- quizzes and quiz solutions
- lab exams and exam material
- instructor-provided PDFs and report templates
- compiled `.exe` files
- nested `.zip` archives
- IDE configuration files
- duplicate files
- most screenshots and generated output

The goal is to document my learning without reproducing the full course or distributing unnecessary academic materials.
