This repository contains **selected coursework and class projects** from **SE 1850 at Iowa State University**.

Rather than publishing every assignment from the course, this repository highlights a curated set of exercises that show my progression with C programming and problem solving.

This is **coursework**, not a single standalone software project.

## 🧪 Selected Labs

### Lab 03 — Functions & DS4 Data

Worked with controller data and functions to process acceleration values, calculate vector magnitude, convert time values, and interpret button input.

### Lab 05 — Conditionals & Orientation

Applied conditional logic and reusable functions to interpret controller orientation from sensor data.

### Lab 06 — Bop-It Style Game

Built an interactive controller-based game using randomized prompts, timing, button input, loops, and conditional logic.

### Lab 07 — DS4 Equalizer

Processed controller values and scaled sensor/joystick data for terminal-based visual output.

### Lab 08 — Moving Averages & Maze Interaction

Implemented moving-average processing and worked with controller motion data in an interactive terminal maze.

### Lab 09 — DS4 Talker

Used controller input, word selection, strings, and `ncurses` to build an interactive text-selection interface.

## 🎮 Final Project — Typing Game

The final project is a terminal-based typing game written in C.

The program:

- Loads words from a text file
- Places words onto a terminal game board
- Moves words through the board over time
- Accepts typed user input
- Tracks a score based on correctly typed words
- Allows words to be added to the word list
- Uses randomized word placement and timing

The project reflects my progression from introductory C exercises to a larger interactive program using functions, arrays, strings, file I/O, randomness, and game logic.

